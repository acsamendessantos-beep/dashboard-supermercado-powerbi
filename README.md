# 📊 Dashboard de Vendas - Supermercado

Dashboard desenvolvido no Power BI para análise do desempenho de vendas
de um supermercado.

## 🎯 Objetivo
Transformar dados de vendas em informações visuais que auxiliem na
análise do desempenho do supermercado.

## 📈 Indicadores
- Vendas Totais
- Ticket Médio
- Quantidade de Produtos
- Marcas Disponíveis
- Produtos Mais Vendidos
- Vendas por Categoria
- Vendas por Forma de Pagamento

## 🛠️ Tecnologias
- Power BI
- DAX
- Power Query
- Excel
- Modelagem de Dados
